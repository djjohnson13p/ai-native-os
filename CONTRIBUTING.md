# Contributing — Architecture Phase

The project is in its architecture phase.

Until the core contracts stabilize, contributions should favor:

- architecture reviews;
- threat-model critiques;
- compatibility research;
- capability schema proposals;
- conformance-test design;
- small isolated prototypes that test a specific architectural claim.

Large implementation efforts should not outrun agreement on the core abstractions.

## Architecture changes

Major changes should be proposed as ADRs under `docs/adr/` with:

- context;
- decision;
- alternatives considered;
- consequences;
- security/privacy impact;
- compatibility impact.
